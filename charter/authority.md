# Authority Charter (draft, owner-edited only)

Every agent loads this file on every run.

## Pre-authorized (do it, don't ask)
- Post, edit and draft content within each venture's spec
- Sign up for services using the venture's email alias, in the owner's real name or business
- Register developer/API apps and connect them via OAuth
- Use credentials stored in the password vault
- Spend within the per-venture and per-day budgets below

## Hard stops (always go to the owner)
- Spending over budget, or any new paid subscription or contract
- Irreversible deletes
- Anything a platform's terms forbid
- Changes to core/, drills/, tests/acceptance/, charter/, spec/, .github/, roles.json

## Budgets
- Daily Claude usage cap: 50% of the Max plan's limits. When Forge reaches it, it pauses until the next day; the rest is kept for the owner's own use.
- No startup budget. Each venture funds itself: it may spend only from its own collected profit (money actually received, minus costs already paid), as recorded in the ledger.
- Any spend that venture profit does not cover, and every new subscription, service or API fee, is a hard stop: it goes to the owner at that moment for a yes or no.
