## What already exists

Most of the 1B pipeline was built in `core/bootstrap.py` through reviewed pull requests before the coverage
ledger existed:

| Req | Role | What the code does today | Gap |
|---|---|---|---|
| 2.2 | Test writer | `real_team()` makes it `CodexAgent(sandbox="workspace-write")`; `_tests_stage` rejects any write outside the task's `test_files` (`tests rejected: wrote outside test_files`), checks the answer against `S_TESTS` and commits only the test files. `validate_task` keeps `test_files` under `tests/` (R1). | None: evidence task. |
| 2.3 | Builder | `ClaudeAgent(permission_mode="acceptEdits")`; `_build_stage` reverts test-file edits, fails out-of-scope changes, checks `S_BUILD` (`done` or `blocked`), and `_check_blocker` demands 2 routes, the error, the capability and "meanwhile" (D-031). | None: evidence task. |
| 2.4 | Judges | Plain code: task tests at exactly the builder commit in a throwaway worktree, then `judge_cmds` (drills, suite), then `_mutation_judge` (D-038 rate gate). | None: evidence task. |
| 2.5 | Reviewer | `CodexAgent(sandbox="read-only")`; `S_REVIEW` verdict and reasons go into the ledger. | **No drift flag**, and nothing checks that the reviewer wrote nothing. Ordinary task. |
| 7.6 | 1B gate | Drills 1-21 exist; none for the 1B gate. No real-agent toy run. | Ordinary gate task. |

Known open item (not a reason to block this plan): the design names `tests/acceptance/` for the test writer,
but the conductor runs tests from `tests/core/` (`core/suite.py`). The write restriction is enforced as the
task's own `test_files`, all under `tests/` (R1).
